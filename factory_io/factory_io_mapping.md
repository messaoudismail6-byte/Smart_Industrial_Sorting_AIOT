# Factory I/O mapping

Create a scene containing:

1. Source / spawner
2. Conveyor
3. Presence sensor
4. Weighing station (simulated)
5. Robot station
6. Bin A
7. Bin B
8. Bin C
9. Reject bin
10. Exit conveyor

For a real Factory I/O installation, map the exported PLC interface to the S7-1200 communication driver or the selected OPC/Modbus bridge.

The repository intentionally keeps the mapping layer technology-neutral so it can be adapted to the exact Factory I/O driver and TIA project version.

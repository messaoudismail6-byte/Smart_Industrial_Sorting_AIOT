# HMI screen specification

## Screen 01 — Overview
- Production status
- Conveyor state
- Current product weight
- Selected bin
- Robot state
- Health score
- Active alarm

## Screen 02 — Production
- Total pieces
- Bin A / B / C counts
- Reject count
- Cycle time
- Throughput

## Screen 03 — AI Predictive Maintenance
- Vibration trend
- Temperature trend
- Motor current
- Health score gauge
- Risk level
- AI recommendation

## Screen 04 — Manual / Service
- Jog conveyor
- Robot service request
- Sensor diagnostics
- I/O status

## Screen 05 — Alarms
- Alarm list
- Timestamp
- Acknowledge
- Reset

Use role-based access for service/configuration screens.
